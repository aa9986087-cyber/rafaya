# الرافعية

لعبة محاكاة ثلاثية الأبعاد للجوال تلعبها لحالك: تبدأ بثلاث خيام وبئر ونخل على الوادي، وتكبّرها لين تصير بلدة ثم مدينة ثم محافظة.

**العب:** https://rafaya.vamosx.workers.dev

- **الوقت:** كل يوم ٢٠ دقيقة بنهار وليل، والنهار أطول بالصيف والليل أطول بالشتاء. المدينة تتحرك كل ساعة من ساعات اللعبة، وفيها أربعة مواسم.
- **البيوت:** خيمة ← بيت طين ← شعبي ← فيلا ← عمارة، إذا توفر لها الطريق والماء والكهرباء والخدمات.
- **الاقتصاد:** ضرائب، ومحلات تبيع على قد صرف الأهالي، ومزارع ومصانع وزوار. ومصاريف مفصّلة: رواتب البلدية، والنظافة، والماء، والطرق، والخدمات. الديون تنص الخدمات، والإفلاس يقفلها.
- **الأرض:** تبدأ بوسط الخريطة، وتشتري الأراضي حولها.
- **المشاريع الكبرى:** بوابة الرافعية، والسوق التراثي، والبرج، والمطار. تنبني على أيام.
- **القرارات:** مشاكل القرية (البئر، العطش، الحمّى، الحريق…) وفرص (مزاين الإبل، الكشتة، العرس…).
- **نشرة الرافعية:** الأهالي يتكلمون عن حال بلدهم بالأرقام، وتختار ردك: وعد أو «نشوف» أو رفض. ويتذكرون وعودك.
- **حفظ تلقائي** في الجوال، والمدينة تكمل وأنت غايب، وكود نسخة احتياطية.

## الملفات

| الملف | وش فيه |
|---|---|
| `js/data.js` | المباني والمراحل والمواسم والأبحاث والمهام والأحداث والقرارات والإنجازات |
| `js/sim.js` | المحاكاة: ساعة كاملة، البناء، التطور، الاقتصاد، الأرض، الحفظ |
| `js/news.js` | نشرة الرافعية: كلام الأهالي، وذاكرتهم، والردود |
| `js/models.js` | كل المباني والناس والإبل والسيارات، مرسومة بأشكال بسيطة |
| `js/world3d.js` | العالم ثلاثي الأبعاد (three.js): الأرض، والإضاءة، والليل والنهار، والحياة |
| `js/main.js` | التحكم باللمس، والواجهة، والشاشات، والساعة |
| `js/sound.js` | الأصوات وأجواء الريح والليل والمطر |
| `vendor/` | three.js (ترخيص MIT) |

صفحات ثابتة بدون أداة بناء. للتشغيل محليًا: `python3 -m http.server` ثم افتح الصفحة.

- **الاختبارات:** `npm test`.
- **الموازنة:** `node test/balance.mjs 1500 42 careful`. الأنواع: careful، spender، taxer، yesman، miser.

## النشر

Worker مستقل باسم `rafaya` على Cloudflare، إعداداته في `wrangler.jsonc`. ما يشارك أي لعبة ثانية في شي.

Cloudflare يبنيه من جذر المستودع مع كل رفع على `main`: ينسخ الملفات اللازمة بس (`scripts/copy-site.mjs`)، وينشرها على https://rafaya.vamosx.workers.dev
