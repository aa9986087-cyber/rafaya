# الرافعية

لعبة محاكاة للجوال تلعبها لحالك: تبدأ بقرية صغيرة (بيوت طين وبئر ونخل على الوادي) وتكبّرها لين تصير بلدة ثم مدينة ثم محافظة.

- **المحاكاة كل يوم:** السكان والهجرة، الوظائف والبطالة، الماء والكهرباء، رضا الناس حسب الخدمات القريبة من بيوتهم، الدخل والضرائب والمصاريف.
- **البيوت تتطور وحدها:** طين ← شعبي ← فيلا ← عمارة، إذا توفر لها الطريق والماء والكهرباء والخدمات.
- **المجلس البلدي:** أبحاث تفتح مباني وتحسينات (الري بالتنقيط، الطاقة الشمسية، التحلية، السياحة…).
- **أحداث:** مطر الوسم، الغبار، الجفاف، رمضان، العيد، موسم التمور، المهرجان.
- **مهام** ترشدك من أول قرية لآخر محافظة، **وحفظ تلقائي** في الجوال، والمدينة تكمل وأنت غايب (يوم كل دقيقتين، حتى ٦٠ يومًا)، **وكود نسخة احتياطية** لنقلها لجهاز ثاني.

## الملفات

| الملف | ماذا فيه |
|---|---|
| `js/data.js` | المباني والمراحل والأبحاث والمهام والأحداث |
| `js/sim.js` | المحاكاة: يوم كامل، البناء، التطور، الحفظ |
| `js/render.js` | رسم الخريطة بزاوية علوية (بدون صور، كله رسم) |
| `js/main.js` | التحكم باللمس، الواجهة، الشاشات، الساعة |

صفحات ثابتة بدون أي أداة بناء: تشتغل على GitHub Pages مباشرة.

```bash
npm test                 # اختبارات المحاكاة (منها رئيس بلدية آلي يكبّر القرية لمدينة)
node test/balance.mjs    # تقرير توازن الاقتصاد على ٤٠٠ يوم
node scripts/bundle.mjs  # نسخة صفحة واحدة للمشاركة: dist/rafaya.html
python3 -m http.server   # ثم افتح http://localhost:8000
```

صُنعت في الرافعية بيد Vamos.
