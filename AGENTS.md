# Rafaya releases

For each player-facing production update, include a short Arabic note at the top of `WHATS_NEW.items` in `js/main.js`. Describe what players will see or how they can use it. Use the existing mode labels and change `WHATS_NEW.v` for each affected mode so the update is marked as new.

Ship the note with the change and verify that the live build includes it under «النشرة ← التحديثات». Add entries for changes that have been approved for production.
